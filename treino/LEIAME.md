# Treino

App de treino da família, publicado em `/treino` junto com cotações e caixa
(mesmo robô de publicação, mesmo fluxo de pull request).

- **Base:** [openGym](https://github.com/DuarteSantos8/openGym), de Duarte Santos, licença AGPL-3.0 (`LICENSE`, `NOTICE.md`). Código-fonte aberto neste repositório, como a licença exige.
- **Modo de uso:** só página pronta, sem servidor. Cada pessoa usa "Continuar sem conta"; os dados ficam no navegador de cada aparelho.
- **Animações dos exercícios:** NÃO estão aqui. São da Gym visual e só podem ser usadas dentro do openGym (ver `NOTICE.md`). Não copiar para este repositório sem decisão do responsável.
- **Montar localmente:** `cd treino/frontend && npm ci && npm run build`.
